```ad-note
title: 静态对象在结构体的作用

- 每个声明的结构体实例 在使用static静态方法的时候**都要导入对应的实例** 否则找不到对应
- 静态变量同理,即全局性改变


```

```cpp title:"结构体中的static-1"
struct Entity
{
	static int x, y;
	
	void Print()
	{
		std::cout << x << "," << y << std::endl;
	}
}

int Entity::x;
int Entity::y;

int main()
{
	Entity e;
	e.x = 2;
	e.y = 3;

	Entity e1;
	e1.x = 5;
	e1.y = 8; 	
	//由于是static e和e1的x,y指向地址一致

	//上面四个赋值都等价于以下两个赋值
	Entity::x =5;
	Entity::y =8;
	
	e.Print();
	e1.Print();
	
	std::cin.get();
}

```

```cpp title:"结构体中的static-2"
struct Entity
{
	int x, y;
	
	static void Print()
	{
		std::cout << x << "," << y << std::endl;
	}
	//静态对象不能访问非静态变量 每个实例(instance)的变量都不一样
	//会报错
}

static void Print(Entity e)
{ //这种处理方法没问题,因为传入了实例e
	//非静态方法在编译的时候的样子
	std::cout << e.x << "," << e.y << std::endl;
}

int main()
{
	Entity e;
	e.x = 2;
	e.y = 3;

	Entity e1;
	e1.x = 5;
	e1.y = 8; 	
	
	Entity::Print();
	
	std::cin.get();
}

```
