```ad-note
title: 联合体

联合体只能有一个成员变量 适合处理名称一样

float a, b, c, d其对应的内存地址都是一样的

**注:这里和C中的union有所区别(和struct的用法)**
```

```cpp title:例子
#include <iostream>

struct Vector2
{
	float x ,y;
};

struct Vector3
{
	float x, y, z;
};

void PrintVector2(const Vector2& vector)
{
	std::cout << vector.x << ", " << vector.y << std::endl;
}

int main()
{
	struct Union{
		union
		{
			float a;
			int b;
		};
	};
	
	Union u;
	u.a = 2.0f;
	
	std::cout << u.a << ", " << u.b << std::endl; //u.b会用浮点数输出表示
	
	std::cin.get();
}
```
