```ad-note
title: enum-枚举
**enumeration** 数值集合
- 集合里面的东西只能是整型或者字符型
- 默认从0开始枚举

```

```cpp title:枚举
#include <iostream>

enum Example : char
{
	A = 5,B,C
	//如果没有指定值后面的元素依次递增5 6 7
	//可以强制指定A=5 B=2 C=7
	//默认从0开始枚举
};

int a = 0; b = 1; c = 2;

int main()
{
	Example value = B; //value取值只能是A B C对应的数字
	if (value == 1)
	{
		//Do sth.
	}
	std::cin.get();
}

```
