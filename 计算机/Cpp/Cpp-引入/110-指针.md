```ad-note
title: 指针

指针是一串保存内存地址的整数

```

```cpp title:指针
int main(){
	void* ptr = nullptr; //nullptr 等价于 NULL 0
	//void类型指针
	//但不管给指针赋予什么类型都无意义，只是方便阅读罢了
	int var = 8; 
	ptr = &var; //把var的内存地址给到ptr
	double* ptr = (double*)&var; 指针类型qiang'g'zhi
}

```
