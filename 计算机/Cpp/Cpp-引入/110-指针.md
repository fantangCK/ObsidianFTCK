```ad-note
title: 指针

指针是一串保存内存地址的整数

**指针的类型是无意义的**

```

```cpp title:指针(栈中)
int main(){
	void* ptr = nullptr; //nullptr 等价于 NULL 0
	//void类型指针
	//但不管给指针赋予什么类型都无意义，只是方便阅读罢了
	int var = 8; 
	ptr = &var; //把var的内存地址给到ptr
	double* ptr = (double*)&var; //类型强制转换 为了规避编译器报错
	//实际上没有改变指针的任何属性
	*ptr = 10; //加上了* 就是给ptr对应的内存地址赋值
}

```

