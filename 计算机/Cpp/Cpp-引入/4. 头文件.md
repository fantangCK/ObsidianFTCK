```ad-note
title: 头文件
include 后面跟着的内容
<iostream>指定的是include系统PATH里面的文件
而“xxx.h”指定的是当前文件夹包含的文件

**注:**
- 在<iostream>的尖括号可以换为"iostream"但反之不行
- c++中iostream普遍不带有.h为了区分c的库文件
- c中则有stdio.h


```

```cpp title:头文件
#pragma once
//保证文件只被编译一次

void InitLog();

void Log(const char* message);

struct Player{};
//如果include本文件多次 由于结构体只能被定义一次 则报错 重定义

```


```cpp title:头文件-重复定义解决方法（旧方法）
#ifndef _LOG_H //如果没被定义 （此方法在编译阶段有一定的空间开销）
#define _LOG_H //则定义LOG_H

void InitLog();//等等函数

 #endif 

```
