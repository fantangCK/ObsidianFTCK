```ad-note
title: 类型双关

不管类型直接操作
Cpp为一个强类型语言 所以并不是所有都能auto (Java木得这样类型系统)

```

```cpp title:例子
#include <iostream>

int main()
{

	std::cin.get();
}
```

```ad-note
title: 类型转换

一种类型 指定转义为另一个(非隐式转换)

```

```cpp title:类型转换
#include <iostream>

int main()
{

	std::cin.get();
}
```
