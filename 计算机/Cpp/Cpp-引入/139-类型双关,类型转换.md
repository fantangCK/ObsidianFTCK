```ad-note
title: 类型双关

不管类型直接操作
Cpp为一个强类型语言 所以并不是所有都能auto (Java木得这样类型系统)

```

```cpp title:例子
#include <iostream>

struct Entity
{
	int x, y;
	
	int* GetPositions()
	{
		return &x;
	}
};

int main()
{
	int a =50;
	double value = a; //类型转换(隐式转换)
	double value = (double)a; //显式转换
	double value = *(double*)&a; //强转因为4bit转8bit 后面的位置都是未初始化的部分
	//类型双关 int到double a的地址给到double指针 再解引用
	//以上都涉及了新建内存
	
	double& value = a; //改变a本身内存
	value = 0.0f //实际上就会崩 8位塞到4位的a内存里面
	
	std::cout << value << std::endl;
	
	
	Entity e = { 5, 8 }; //结构体是没有任何类型填充的 如果结构体啥也没有 至少占一个字节
	int* position = (int*)&e;	//传结构体地址 指针
	std::cout << position[0] << ", " << position[1] << std::endl; //将结构体当数组用
	
	int y = *(int)((char*)&e + 4); 
	//给e的地址转为char类型指针 然后移动4字节 再转为int类型指针
	//神经写法 别这么写好嘛(x_x) 尼玛你用个e.y都行啊
	
	int position = e.GetPositions(); //传递地址
	position[0] = 2; //然后用数组解
	
	std::cin.get();
}
```

```ad-note
title: 类型转换

一种类型 指定转义为另一个(非隐式转换)

包含static_cast reinterpret_cast(类型双关转换) dyanmic_cast const_cast
```

```cpp title:类型转换
#include <iostream>

class Base
{
public:
	Base() {}
	virtual ~Base() {}
};

class Derived : public Base
{
public:
	Derived() {}
	~Derived() {}
};

class AnotherClass : public Base
{
public:
	AnotherClass() {}
	~AnotherClass() {}
};


int main()
{
	//C风格转换
	double value = 5.25;
	double a  = (int)value + 5.3; //这里强转int丧失精度
	std::cout << a << std::endl;
	
	//C++风格
	double s = static_cast<int>(value) + 5.3; //会检查转换是否合法
	double t = reinterpret_cast<AnotherClass*>(&value); //类型双关
	
	
	Derived* derived = new Derived(); 
	Base* base = derived; //这里表明base位derived的类实例(指针)
	
	AnotherClass* ac = dynamic_cast<AnotherClass*>(base); //这里ac不成功
	//dynamic_cast是一个好操作方法来查看转换是否成功 不成功ac转为nullptr
	
	Derived* ac = dynamic_cast<Derived*>(base); //这里ac正常获取
	
	//const_cast //移除或者添加变量const限定
	
	//两种方法结果其实一样 C++是直接操作 可以控制是否要检查操作是否合法 另外易于阅读
	std::cin.get();
}
```

```ad-note
title: dynamic_cast

C++中类型转换的一种 运行时转换 不是编译阶段 有一定内存开销

常常用于检验 父类 转为 派生类 为是否正确,转换错误返回空指针null
```

```cpp title:dynamic_cast
#include <iostream>

class Entity
{
public;
	virtual void PrintName() {}
};

class Player : public Entity
{
};

class Enemy : public Entity
{
};


int main()
{
	Entity* player = new player; //可以用Player类 这里做演示用父类

	Entity* e1 = new enemy();
	
	Player* p = (Player*)e1; //这里是强制转换 是危险的 e1就是enemy不是player
	Player* p = static_cast<Player*>(e1); //和上面一样不会报错
	//如果使用dynamic-cast
	
	Entity* player = new player;
	Entity* e1 = new enemy();
	Player* p = dynamic_cast<Player*>(e); 
	//此处会报错 dynamic_cast为适用于多态 需要有虚函数表
	
}
```
