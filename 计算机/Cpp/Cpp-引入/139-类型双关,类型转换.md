```ad-note
title: 类型双关

不管类型直接操作
Cpp为一个强类型语言 所以并不是所有都能auto (Java木得这样类型系统)

```

```cpp title:例子
#include <iostream>

struct Entity
{
	int x, y;
};

int main()
{
	int a =50;
	double value = a; //类型转换(隐式转换)
	double value = (double)a; //显式转换
	double value = *(double*)&a; //强转因为4bit转8bit 后面的位置都是未初始化的部分
	//类型双关 int到double a的地址给到double指针 再解引用
	//以上都涉及了新建内存
	
	double& value = a; //改变a本身内存
	value = 0.0f //实际上就会崩 8位塞到4位的a内存里面
	
	std::cout << value << std::endl;
	
	std::cin.get();
}
```
