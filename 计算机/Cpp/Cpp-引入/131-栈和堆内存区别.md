
```ad-note
title: 栈和堆内存区别
## 大小:
- 堆和栈内存在物理内存中容量大小不一样(50M就要在堆上)
---
## 申请过程中:
- 栈内存:在cpu cache line上几乎没有cache miss所以访问的很快
- 堆内存:在申请中可能会是一些cache miss(这里分hit`命中` miss`没有命中`)
	- 内存分配表:	借出多少内存 回收多少 哪里空闲 等等信息

<sub>**实际上分配的时间是内存开销的大头(堆内存查找再分配 栈内存在汇编上直接对寄存器操作)**</sub>
<sub>**tips:如果在运行前直接分配4G空间 然后操作 此时堆和栈运行效率是一致的 (这造成很多内存浪费的 Bad!)**</sub>

---
## 生存周期:
- 栈内存:仅限作用域(参考[127-栈作用域生存期,智能指针](127-栈作用域生存期,智能指针.md))
- 堆内存:除非程序结束 还有delete直接释放


```

```cpp title:栈和堆内存区别

#include <iostream>
#include <string>
struct Vector3
{
	float x, y, z;
	
	Vector3()
		: x(10), y(11), z(12);
};

int main()
{
	
	int value = 5;
	int array[5];
	array[0] = 1;
	array[1] = 2;
	array[2] = 3;
	array[3] = 4;	//这几个数字在内存是反向存储的(像栈一样一个塞一个 然后指针往内存后移动)
	array[4] = 5;	//内存上这五个都是连续在一起的
	Vector3 vector; //vector上三个数也是在一起的
	//栈上
	
	int* hvalue = new int; //new其实调用了malloc(在 内存空闲列表 去查询并分配空间)
	*hvalue = 5;
	harray[0] = 1;	//tips:批量加h shift+alt
	harray[1] = 2;
	harray[2] = 3;
	harray[3] = 4;
	harray[4] = 5;
	int* harray =  new int[5];
	Vector3* hvector = new Vector3(); 
	
	delete hvalue; //这里同理调用了free
	delete[] harray;
	delete hvector
	//堆上 (需要释放内存 也可以用智能指针)
	
	std::cin.get();
}
```
