```ad-note
title: 多返回值

C++默认是不能return两个值的

处理办法
- 传出一个结构体
- 传入用引用 然后直接对 传入值赋值(变向传出了多个值) 性能要比传出结构体要好

```

```cpp title:多返回值-结构体
#include <iostream>

// 定义结构体来存放多个值
struct Result {
    int value1;
    int value2;
};

// 函数返回结构体
Result getValues() {
    Result res;
    res.value1 = 10;
    res.value2 = 20;
    return res;
}

int main() {
    Result result = getValues();
    std::cout << "Value1: " << result.value1 << ", Value2: " << result.value2 << std::endl;
}

```

```cpp title:多返回值-引用
#include <iostream>
using namespace std;

// 函数通过引用参数传出多个值
void getValues(int &value1, int &value2) {
    value1 = 10;
    value2 = 20;
}

int main() {
    int val1, val2;
    getValues(val1, val2);
    std::cout << "Value1: " << val1 << ", Value2: " << val2 << std::endl;
    return 0;
}

```
