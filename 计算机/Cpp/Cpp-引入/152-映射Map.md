```ad-note
title: 映射Map

都是一种键值对的数据结构（像是哈希表等）方便的去查找
相比于向量下标 需要慢慢查找需要的元素
主要是两种`std::map` `std::unordered_map`
- 前者用于自平衡的二叉搜索树(红黑树)
- 后者主要就是哈希表(除非需要排序 用后者最快)

```

```cpp title:引入
#include <iostream>
#include <vector>

#include <map>
#include <unordered_map>

struct CityRecord
{
	std::string Name;
	uint64_t Population;
	double Latitude, Longtitude;
} 

int main()
{
	std::vector<CityRecord> cities;
	
	cities.emplace_back("Mellburne", 500000, 2.4, 9.4);
	//这里使用emplace_back避免构建临时变量
	cities.emplace_back("Lol-town", 500000, 2.4, 9.4);
	cities.emplace_back("Berlin", 500000, 2.4, 9.4);
	cities.emplace_back("Paris", 500000, 2.4, 9.4);
	cities.emplace_back("London", 500000, 2.4, 9.4);
	
	//查找Berlin人口
	for (const auto& city : cities)
	{
		if (city.Name == "Berlin" )
		{
			city.Population; //berlin
			break;
		}
	}
	
	std::cin.get();
}
```

```cpp title:哈希表
		}
```
