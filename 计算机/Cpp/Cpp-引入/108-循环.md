```ad-note
title: 循环

两种类型

- while


```

```cpp title:for循环
for(int i = 0; i < 5; i++){
	//声明值; 判断值; 对迭代体进行变换
	//这三者都可以单独分离开
	//i一般指 iteration迭代数
	// i++指的是后加 ++i为先加
}
//分离写法
int i = 0;
bool condition = true;
for(;condition;)
{
	i++
	if(!(i<5))
		condition = false;
}

```

```cpp title:while循环
int i =0;
while(i < 5)//一般作为已有变量基于此循环
{
	//循环运行的代码
}
//少见的do-while循环
do{
	//无论如何此部分代码都会被先执行一边
} while(i < 5)

```
