```ad-note
title: 继承

继承是包含父级的内容 子集做的操作是可以改变父级内的变量,调用父级的函数等等

class C2 : public C1
从C1中继承public内容 并放到C2中

```

```cpp title:继承
 #include <iostream>
 
class Entity
{
public:
	float X,Y;
	
	void Move(float xa,float ya)
	{
		X += xa;
		Y += ya;
	}
};

class Player : public Entity
{	//继承-多态
public:
	const char* Name;
	
	void PrintName()
	{
		std::cout << name << std::endl
	} 
};

int main()
{
	std::cout << sizeof(Entity) << std::endl
	//包含两个变量X Y 输出8
	std::cout << sizeof(Player) << std::endl
	//还包括char* Name 所以会多于8个
	//此处32位系统位 输出为12(指针4字节)
	//64位系统还要考虑小端存储 对齐问题 输出为16(指针8字节)
	Player.Move(5 ,5);
	Player.x = 5; //都是合法的
	
	std::cin.get();
}
```
