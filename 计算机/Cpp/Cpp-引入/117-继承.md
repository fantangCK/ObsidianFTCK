title: 继承
# **基本概念**

- **定义**：继承是面向对象编程的核心特性，允许一个类（子类/派生类）基于另一个类（父类/基类）构建。
    
- **目的**：
    - **代码复用**：子类可以直接使用父类的成员。
    - **功能扩展**：子类可以添加新成员或重写父类成员。
    - **多态性**：通过虚函数实现运行时多态。

---

# **2. 继承的访问控制**

- **访问修饰符**：
    - `public`：父类的 `public` 和 `protected` 成员在子类中保持原访问权限。
    - `protected`：父类的 `public` 和 `protected` 成员在子类中变为 `protected`。
    - `private`：父类的 `public` 和 `protected` 成员在子类中变为 `private`。
- **注意**：父类的 `private` 成员不能在子类中直接访问。
    

---

# **3. 子类对父类的操作**

- **访问成员**：子类可以直接访问父类的 `public` 和 `protected` 成员。
- **修改成员**：子类可以修改父类的 `public` 和 `protected` 成员变量。
- **调用函数**：子类可以调用父类的 `public` 和 `protected` 成员函数。

---

# **4. 禁止继承：`final` 关键字**

- **C++11 引入**：用于禁止类被继承或虚函数被重写。
- **用法**：
    - 禁止类被继承：`class ClassName final { ... };`
    - 禁止虚函数被重写：`virtual void func() final { ... }`
    
---

# **5. 构造函数与析构函数**

- **构造函数**：
    - 子类构造函数会先调用父类构造函数。
    - 若父类无默认构造函数，子类需显式调用父类构造函数。
- **析构函数**：
    - 子类析构函数先执行子类逻辑，再调用父类析构函数。
- **参考**
	- [118-虚函数](118-虚函数.md) [116-析构函数](116-析构函数.md)

```cpp title:继承
 #include <iostream>
 
class Entity
{
public:
	float X,Y;
	
	void Move(float xa,float ya)
	{
		X += xa;
		Y += ya;
	}
};

class Player : public Entity
{	//继承-多态
public:
	const char* Name;
	
	void PrintName()
	{
		std::cout << name << std::endl
	} 
};

int main()
{
	std::cout << sizeof(Entity) << std::endl
	//包含两个变量X Y 输出8
	std::cout << sizeof(Player) << std::endl
	//还包括char* Name 所以会多于8个
	//此处32位系统位 输出为12(指针4字节)
	//64位系统还要考虑小端存储 对齐问题 输出为16(指针8字节)
	Player.Move(5 ,5);
	Player.x = 5; //都是合法的
	
	std::cin.get();
}
```

#include <iostream>

class Base {
public:
    int x;
};

//class Der1 : public Base {};
//class Der2 : public Base {};

//正确处理办法为使用virtual 虚继承
class Der1 : virtual public Base {};
class Der2 : virtual public Base {};

class Final : public Der1, public Der2 {};

int main() {
    Final obj;
    obj.x = 10; // 存在二义性，无法确定是 Der1::x 还是 Der2::x
}
