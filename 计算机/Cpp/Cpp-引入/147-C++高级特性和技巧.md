```ad-note
title: 左值与右值

左值有实际存储空间

注意
- ~~等号右边就是右值~~
- 右值不只是字面量 也可以是函数返回结果

```

```cpp title:左值与右值
#include <iostream>

int Getvalue()
{
	return 10;
}

int& Getvalue() //左值引用
{
	static int value = 10;
	return value;
}

void SetValue(const int& value) //同时支持了左值和右值
{
}

int main()
{
	int i = 10;
	//左值 右值
	int a = i;
	int i = GetValue();
	
	const int& a = 10; //特殊规则 等价于
	/*
	int temp = 10; //创建了一个临时的左值
	const int& a  = temp;
	*/
	GetValue() = 5;
	
	SetValue(i); //i是左值
	SetValue(10); //10是临时右值 传入的时候被作为左值
	
	std::cin.get();
}
```
