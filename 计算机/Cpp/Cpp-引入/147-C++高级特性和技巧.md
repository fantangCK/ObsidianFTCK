```ad-note
title: 左值与右值

常见错误:
等号右边就是右值
左值不一定完全是被赋值对象 右值也不一定是字面量

```

```cpp title:左值与右值
#include <iostream>

int main()
{
	int i = 10;
	//左值 右值
	int a = i;
	std::cin.get();
}
```
