```ad-note
title: 控制流程语句

- continue 用于循环 表示进入下一个迭代
- break 跳出循环 终止循环
- return 直接退出函数(如果有返回值 则在此返回)
- switch - case
	- `case` 后接具体的值，如果 `day` 的值匹配，则执行相应的 `case` 块中的代码。
	- `break` 用于跳出 `switch` 语句，防止执行后续的 `case`。
	- `default` 用于处理没有匹配的情况，类似于 `else`，如果没有任何 `case` 匹配，将执行 `default` 的代码。
```

```cpp title:continue
int main(){
	for(int i = 0; i < 5; i++)
	{
		if (i % 2 ==0)
			continue; //跳过两次循环不输出
		std::cout << "Hello World!" << std::endl
	}
}	//最终输出两个Hello World
```

```cpp title:break
int main(){
	for(int i = 0; i < 5; i++)
	{
		if (i % 2 ==0)
			break; //直接停止整个for
		std::cout << "Hello World!" << std::endl
	}
}	//最终什么也没有
```

```cpp title:return
int main(){
	for(int i = 0; i < 5; i++)
	{
		if (i % 2 ==0)
			return 0; //直接跳出main函数
			//return 需要有返回值
		std::cout << "Hello World!" << std::endl
	}
}
```

```cpp title:"switch - case"
#include <iostream>

int main(){
    int day = 3; // 假设星期三
    switch(day) {
        case 1:
            std::cout << "星期一" << std::endl;
            break;
        case 2:
            std::cout << "星期二" << std::endl;
            break;
        case 3:
            std::cout << "星期三" << std::endl;
            break;
        case 4:
            std::cout << "星期四" << std::endl;
            break;
        case 5:
            std::cout << "星期五" << std::endl;
            break;
        default:
            std::cout << "不是有效的星期" << std::endl;
            break;
    }
}
```
