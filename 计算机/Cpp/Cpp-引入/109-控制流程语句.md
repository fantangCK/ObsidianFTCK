```ad-note
title: 控制流程语句

- continue 用于循环 表示进入下一个迭代
- break 跳出循环 终止循环
- return 直接退出函数(如果有返回值 则在此返回)

```

```cpp title: continue
int main(){
	for(int i = 0; i < 5; i++)
	{
		if (i % 2 ==0)
			continue; //跳过两次循环不输出
		std::cout << "Hello World!" << std::endl
	}
}	//最终输出两个Hello World
```

```cpp title: break
int main(){
	for(int i = 0; i < 5; i++)
	{
		if (i % 2 ==0)
			break; //直接停止程序
		std::cout << "Hello World!" << std::endl
	}
}	//最终输出两个Hello World
```
