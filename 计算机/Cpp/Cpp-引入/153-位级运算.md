```ad-info
title:位级运算
主要就是六种主要运算
- `<<` 	左移运算符
	- 字节比特位层面移动n位 数值扩大2<sup>n</sup>倍
- `>>` 	右移运算符
	- 同理 但是还要考虑截取
- `&`		与运算符	AND
	- 适用截取操作
- `|`		或运算符	OR
	- 适用填充操作
- `^`		异或运算	XOR
	- 常用于交换 判断是否相同
- `~`		非运算	NOT
	- 嗯,常用于取反

编码表示参考CSAPP(或 计算机组成原理) 运算部分含汇编知识

注:
这些运算都可以写重载
另外一般情况下5x16这种运算编译器会自动重写为5 << 4
`C++89`开始有了十六进制字面量0x 前缀
`C++14`提供了二进制字面量0b 前缀
```

```cpp title:位级运算案例
#include <iostream>
#include <bitset>

int main()
{
	int a = 0b101;
	int b = 0b10110;
	b <<= 4;
	int c = a | b;
	std::cout << std::bitset<9>(c) << std::endl; //bitset提供二进制输出
	std::cin.get();
}
```
