```ad-note
title: 命名空间

避免命名冲突 例如初始化Init

符号使用:: 类也是一样可以使用
**命名空间是有作用域的**

---
<sub>**注:
在纯C的库中一般函数名和变量等等 会带有类似namespce的标签 例如GLFWCreateWindows glGenVertexBuffer**
</sub>
```

```cpp title:命名空间
#include <iostream>
#include <string>
#include <algorithm>

namespace apple{
	namespace functions
	{
		void print(const char* text)
		{
			std::cout << temp << std::endl;
		}
	}
	
	void print_again();
} 

namespace orange{
	void print(const char* text)
	{
		std::string temp = text;
		std::reverse(temp.begin(), temp.end());
		std::cout << temp << std::endl;
	}
}

int main()
{
	//using namespace apple; //完全引入
	using apple::print(); //引入apple空间的print
	namespace a  = apple; //命名空间重命名
	
	using namespace apple::functions; //一步引用
	
	apple::functions::print("Hello");
	apple::print_again();
	
	std::cin.get()
}

```

```ad-note
title: 不使用using namepace std

## 原因:
- 使用std可以指出使用的是标准模板库和c++库(EASTL 和标准 STL)
	- 不同命名法区别
		- 帕斯卡命名法-每个单词首字母大写,中间不得有空格下划线
		- 驼峰命名法-首字母大写...(待补充区别)
		- 蛇形命名法-Cpp写法
- namespace冲突 debug灾难
- 除非自己写的库要不然不要使用using namespace

---

## 注意:
- using namespace std在于作用域 不在作用域内的函数等还是要写std的
- 头文件中不要使用using namespace

```

```cpp title:案例
#include <iostream>
#include <string>
#include <algorithm>

namespace apple{
	void print(const std::string& text)
	{
		std::cout << temp << std::endl;
	}
}

namespace orange{
	void print(const char* text)
	{
		std::string temp = text;
		std::reverse(temp.begin(), temp.end());
		std::cout << temp << std::endl;
	}
}


using namespace apple;
using namespace orange;

int main()
{
	print("Hello");	//const char类型 默认是走orange命名空间
					//如果走apple命名空间涉及一个隐式转换
	
	apple::print("Hello"); //最好还是包含apple::
	
	std::cin.get()
}
```
