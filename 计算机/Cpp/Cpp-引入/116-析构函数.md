```ad-note
title: 析构函数

波浪号~加上类的对象

用于清理手动分配的内存 超出作用域**自动调用析构函数**

```

```cpp title:析构函数

class Entity
{
public:
	float X,Y;
	
	Entity()
	{
		X = 0.0f;
		Y = 0.0f;
		std::cout << "Created Entity!" << std::endl;
	}
	
	~Entity() //析构函数
	{
		std::cout << "Destroyed Entity!" << std::endl;
	}
	
	void Print()
	{
		std:cout << X << "," << Y <<std::endl;
	}
}

void Function()
{ //栈上创建
	Entity e;
	e.Print();
	//e.~Entity(); //手动调用方法,不常用
} //作用域结束跳回Function()调用位置
//同时调用析构函数

int main()
{
	Function();
	std:cin.get();
}
```
