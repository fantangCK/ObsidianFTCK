```ad-note
title: 析构函数

波浪号~加上类的对象

用于清理手动分配的内存 超出作用域**自动调用析构函数**

```

```cpp title:析构函数

class Entity
{
public:
	float X,Y;
	
	Entity()
	{
		X = 0.0f;
		Y = 0.0f;
		std::cout << "Created Entity!" << std::endl;
	}
	
	~Entity() //析构函数
	{
		std::cout << "Destroyed Entity!" << std::endl;
	}
	
	void Print()
	{
		std:cout << X << "," << Y <<std::endl;
	}
}

void Function()
{ //栈上创建
	Entity e;
	e.Print();
	//e.~Entity(); //手动调用方法,不常用
} //作用域结束跳回Function()调用位置
//同时调用析构函数

int main()
{
	Function();
	std:cin.get();
}
```

```ad-note
title: 虚析构函数

处理类继承的 虚函数 和 析构函数的结合
保证析构在子类继承的时候能被正确调用(有内存溢出的潜在风险)

```

**虚函数参考 [118-虚函数](118-虚函数.md)**

```cpp title:例子
#include <iostream>

class Base
{
public:
	Base() { std::cout << "Base Constuctor\n"; }
	virtual ~Base() { std::cout << "Base Destuctor\n"; }
};	//这里需要标记为虚函数 意味着这个类可能被扩展为子类 还有别的析构函数要调用这个

class Derived : public Base
{
public:
	Derived() { m_Array = new int[5]; std::cout << "Derived Constuctor\n"; }
	~Derived() { delete[] m_Array; std::cout << "Derived Destuctor\n"; }
private:	//这里析构函数没有被调用
	int* m_Array;
};

int main()
{ 
	Base* base = new Base();
	delete base;
	
	std::cout << "-----------------------------\n";
	
	Derived* derived = new Derived();//Derived先调用Base构造 自身再构造
	delete derived;	//自身先析构 再调用Base的析构
	
	std::cout << "-----------------------------\n";
	
	Base* poly = new Derived(); //构造一切正常
	delete ploy; //析构就有问题了 是只调用Base析构
	//因为Derived类 被赋值给 Base类型指针对象poly 它再析构的时候不知道有另一个析构函数
	//另一个析构函数没有被标记为虚函数
	
	std::cin.get();
}
```
