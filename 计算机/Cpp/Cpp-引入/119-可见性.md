```ad-note
title: 可见性

有三个可见性修饰符private protected public
- private: 仅类内部能调用
- protected: 继承类可以调用
- public: 都可以调用

**只是为了方便人去阅读**

```

```cpp title:可见性
class Entity
{
private:
	int X, Y; //仅Entity内的 函数能访问此变量
	
	void Print(){}

protected:
	int A, B;
public:
	Entity()
	{
		X = 0;
	}
};

class Player : public Entity
{
public:
	Player()
	{
		//X = 2; //不合法操作,及时是继承因为private不能直接访问
		A = 2; //继承自前面的类 因为protected 而能访问
	}
}
int main()
{
	Entity e; //创建实例
	//e.Print();
	//e.X = 5; //都不合法,原因同上
	
	
	std::cin.get();
}
```
