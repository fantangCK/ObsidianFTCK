```ad-note
title: 异常处理
C++中的异常处理机制允许程序在运行时处理错误或异常情况，避免程序崩溃。通过`try`、`catch`和`throw`关键字，可以实现对异常的捕获和处理。

关键点：
1. **try块**：用于包裹可能抛出异常的代码。
2. **catch块**：用于捕获并处理特定类型的异常。
3. **throw**：用于抛出异常。

```

```cpp title:异常处理
#include <iostream>
#include <stdexcept> // 包含标准异常类

int divide(int a, int b) {
    if (b == 0) {
        throw std::invalid_argument("除数不能为零！");
    }
    return a / b;
}

int main() {
    try {
        int result = divide(10, 0);
        std::cout << "结果是: " << result << std::endl;
    } catch (const std::invalid_argument& e) {
        std::cerr << "捕获到异常: " << e.what() << std::endl;
    }

    std::cin.get();
    return 0;
}
```

```ad-note
title:异常与枚举类的妙用

在C++中，枚举类（`enum class`）可以用于定义一组特定的错误类型，结合异常处理机制，能够使代码更具可读性和可维护性。
1. **枚举类**：用于定义一组相关的常量，避免命名冲突。
2. **异常处理**：通过抛出和捕获异常，实现错误管理。
3. **自定义异常**：可以结合枚举类定义更具体的异常类型。

参考 [112-类](112-类.md) [114-枚举](114-枚举.md)
```

```cpp title:异常与枚举类的妙用
#include <iostream>
#include <stdexcept>
#include <string>

// 定义错误类型的枚举类
enum class ErrorCode
{
    DivisionByZero,
    NegativeValue,
    InvalidInput
};

// 自定义异常类，包含错误码和描述
class CustomException : public std::exception
{
private:
    ErrorCode code;
    std::string message;

public:
    CustomException(ErrorCode code, const std::string& message)
        : code(code), message("错误码: " + std::to_string(static_cast<int>(code)) + " - " + message) {}


    const char* what() const noexcept override
    {
        return message.c_str();
    }
	/*	const 不改变传入变量
	* 	noexcept 表示这个函数不会抛出异常
	*	override 重写
	* 	to_string 将数字(枚举数)转为字符串并链接
	*	c_str 输出c风格字符串
	*/
	
    ErrorCode getCode() const { return code; }
};

// 函数：检查输入并抛出异常
int divide(int a, int b) {
    if (b == 0)
    {
        throw CustomException(ErrorCode::DivisionByZero, "除数不能为零！");
    }
    if (a < 0 || b < 0)
    {
        throw CustomException(ErrorCode::NegativeValue, "输入值不能为负数！");
    }
    return a / b;
}

int main() {
    try {
        int result = divide(10, -5); // 测试负数输入
        std::cout << "结果是: " << result << std::endl;
    }
    catch (const CustomException& e)
    {					//这里使用引用 减少拷贝
        std::cerr << "捕获到异常: " << e.what() << std::endl;
        //对于输出错误代码这种情况使用cerr直接输出 不需要和cin一样进入缓冲区
        if (e.getCode() == ErrorCode::DivisionByZero)
        {
            std::cerr << "处理除零错误..." << std::endl;
        }
        else if (e.getCode() == ErrorCode::NegativeValue)
        {
            std::cerr << "处理负数输入错误..." << std::endl;
        } 
    }

    std::cin.get();
    return 0;
}
```
