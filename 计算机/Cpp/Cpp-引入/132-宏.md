```ad-note
title: 宏

由预处理器优化代码(送给编译器之前的操作) 纯粹的代码文本替换

尽量不要频繁使用,降低代码可读性

tips:debug用法	(VS2022中预制的是_DEBUG 和 NDEBUG)
- _DEBUG	![](附件/Pasted%20image%2020250213230555.png)
- NDEBUG	![](附件/Pasted%20image%2020250213230802.png)
```

```cpp title:宏-实例
#include <iostream>
#include <string>

#define OPEN_CURLY {	//宏
#define WAIT std::cin.get()	//宏 (实际上可以把分号也移动过来)


int main()
OPEN_CURLY	//bro!仅作展示 真这么写还是卷铺盖走人吧
	
	WAIT;	//bro!仅作展示 工程中不要这么写(如果WAIT塞到别的什么include里面 要翻半天的!)
}			//再次吐槽: 迷惑行为大赏
```


```cpp title:宏
#include <iostream>
#include <string>

#define LOG(x) std::cout << x << std::endl	//最好还是别加分号
//函数简化

//debug使用法
#ifdef _DEBUG //debug模式
#define LOG(x) std::cout << x << std::endl //定义这个函数
#else	//否则
#define LOG(x)	//将LOG(x)替换为空
#endif	//结束定义

//或者	
#define DEBUG 1 //手动定义参数 也可以在属性设置里面指定参数(VS2022中 DEBUG=1 不能有空格)

#if DEBUG == 1
#define LOG(x) std::cout << x << std::endl
#elif defined(RELEASE)
#define LOG(x)
#endif

int main()
{	
	//std::cout << "Hello" << std::endl;	//等价于
	LOG("Hello");
	std::cin.get();
}
```
