```ad-note
title: 预编译头文件

抓取一堆头文件 转换为编译器可用格式 使其不必一次又一次读取这些文件

减少每次编译所需时间(同理 不要经常修改预编译文件)
一般来说像是是STL库 WindowsAPI这些文件

业务依赖不放在pch里 底层依赖放在pch中

Visual Studio一般命名为stdafx.h

```

```cpp title:预编译头文件-主程序
#include "pch.h"

int main()
{
	std::cout << "Hello World" << std:endl;
	std::cin.get();
}
```
