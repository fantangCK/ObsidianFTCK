```ad-note
title: 函数
函数的入口参数 参数类型 都要有

Debug下没有返回值会报错,实际生产Release可以没有<sub>***(但不是好习惯 (¬‿¬) )***</sub>


```

```cpp title:例子
#include <iostream>

int Multiply(int a, int b)
{
	return a * b;
}
//不同的函数拆分方式
void MultiplyAndLog(int a, int b)
{
	int result1 = Mutiply(a, b);
	std::cut << result1 << std::endl;
}

int main(){
	//int main入口函数的返回值可以没有
	int result1 = Mutiply(3, 2);
	
	std::cut << result1 << std::endl;
	std::cin.get();
	
	MutiplyAndLog(90, 45);
}
```
