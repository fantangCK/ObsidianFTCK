```ad-note
title: 引用

引用为指针的扩展
- 引用ref是a的别名,变量和ref指向相同地址
- 引用被定义后就不能修改 ~~ref = b;~~
```

```cpp title:引用
int main()
{
	int a = 5;
	int* b= &a;
	int& ref = a;//这里是一个引用
	//ref为a的别名,变量和ref指向相同地址
	ref = 2;
	//编译的时候没有这部分地址
	//ref = b;
	//注意: 引用被定义后就不能修改
}
```


```cpp title:函数引用用法
void Increment(int& value)
 {
 	value++;
 }
 
 void Increment1(int* value)
 {
 	(*value)++;
 }
 
 void Increment2(int& value)
 { //此方法更简洁
 	value++;
 }
 
 int main(){
 	int a = 5;
	Increment(a);//此时不改变实参 a输出还是5
	
	Increment1(&a);//传入a的地址
	std::cout << a << std::endl;
	
	Increment2(a);
	std::cout << a << std::endl;
}
```
