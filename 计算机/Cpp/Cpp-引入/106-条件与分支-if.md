```ad-note
title: 条件分支
if 条件判断
可配合else做分支

**注:**
- else if不是关键词 其实是else{ if }嵌套
- 判断 汇编采用TEST 跳转有JMP JE JNE等等 

```

```cpp title:if判断
int main()
{
	const char*ptr "Hello";
	if (ptr) //if里面的值只判断是否为0 即bool False
		Log(ptr);
	else if (ptr ="Hello")
		Log("Ptr is Hello!");
	std:cin.get();
}
```
